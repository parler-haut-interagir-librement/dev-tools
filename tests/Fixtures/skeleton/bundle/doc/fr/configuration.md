# Configuration

La configuration du bundle se trouve sous `tilttek_example` :

```yaml
# config/packages/tilttek_example.yaml
tilttek_example:
    enabled: true
```

| Option | Valeur par défaut | Effet |
|---|---|---|
| `enabled` | `true` | Enregistre les services du bundle ; `false` n'en enregistre aucun. |
