# Points d'extension

Le paquet est en `0.x` : ses points d'extension sont stables seulement à partir de sa version 1.0. D'ici là, une
version mineure peut les changer, et son CHANGELOG dit comment.

| Pour | Faites |
|---|---|
| Remplacer un service | Créez un alias de l'interface que le bundle enregistre vers votre propre service |
| Ajouter au bundle | Étiquetez un service avec une étiquette que cette page énumère ; le bundle recueille tous les services ainsi étiquetés |
